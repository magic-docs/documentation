This folder hosts downloadable installer assets for Docs Indexer releases.

- Architecture: x64
- Installer: `indexer/v1.0.0/DocsIndexer-Setup-x64-v1.0.0.exe`

https://raw.githubusercontent.com/magic-docs/documentation/main/indexer/v1.0.0/DocsIndexer-Setup-x64-v1.0.0.exe

`/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-`

## Update process

For a new version:

1. Add a new version folder, for example `indexer/v1.0.1/`.
2. Upload the matching installer and checksum files.
3. Keep older versions available for rollback.
